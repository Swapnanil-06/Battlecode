# Game Reveal Checklist

Action items to complete immediately after the game engine and bot API reveal on 13 October 2026 at 09:00 UK:

- [ ] **Read full game spec**: Study game mechanics, constraints, turn order, scoring rules, and API specifications.
- [ ] **Download engine**: Obtain the official game runner, starter packages, and documentation.
- [ ] **Run example match**: Verify the game engine and visualizer/replays by executing a local match with default/starter bots.
- [ ] **Put a trivial legal bot on the ladder**: Build and submit a minimal valid bot to verify the submission workflow and establish a baseline presence on the ladder.
- [ ] **Set up local match automation**: Create automated scripts in `runner/` to execute local head-to-head matches and benchmark bots quickly.
